Throwaway harness for the Google Identity Services token flow — it isolates authorization from the rest of Kinetos. Serve it from an origin registered under Authorized JavaScript origins (e.g. http://localhost:8080) and tap the buttons in order. Delete this file once you trust the real flow.

Standalone PWA caveat: a plain page can't reproduce the installed-app window. To check that case, use the real app (Profile → Cloud sync → Connect) after deploying.
