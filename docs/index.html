Kinetos — project context

Offline-first PWA to plan and track gym workouts. Vanilla JS (ES modules), no build step, no backend, data in localStorage. These docs are written to give a future session enough context to continue work quickly.

What it does

  • Exercises — 64 built-in exercises across groups (incl. a Warm-up group), each with an inline SVG "muscle map" illustration and how-to cues (all in 5 languages). Users can add custom ones. Equipment includes a resistance band.
  • Plan — create planned sessions (name, date, exercises with target sets/reps/weight); reorder exercises.
  • Session logging — log sets with weight/reps, time, distance, or a counted tally (e.g. stair-stepper stairs); tap a pending set to open the set runner (stopwatch + value ± + three effort buttons) so each set's real duration is recorded; per-set effort rating (easy/medium/hard); completion timestamps (seconds); add/remove sets (swipe-delete with Undo); collapse exercises and press-and-hold the thumbnail to reorder; live timer; number fields open a chooser on tap and accept typing after a hold; configurable rest timer after each done set; plate calculator (tap a barbell weight field); PR badges on finished sessions.
  • Suggestions — effort- and performance-aware next-set targets (miss reps → back off, beat them → push); shown as a chip you can apply, and on the exercise detail. See Extending.
  • Progress — Day/Week/Month/Year selector scoping stats + volume chart; sets by muscle group; estimated 1RM trend; average effort. Uses Chart.js if present, else a built-in fallback.
  • Profile — name, photo, sex, birthdate, height, weight, resting HR, activity level; auto-calculated metrics: max HR + HR zones, BMI + body-fat, BMR + TDEE, 1RM. JSON export/import, per-set CSV export, rest-timer, plate, bar-weight & rep-preset settings + reset.
  • Cloud sync (optional, off by default) — back up to your own Google Drive. See Cloud sync.
  • Cross-cutting — 5 languages (EN/DE/FR/ES/RU), light/dark themes, installable, fully offline via a service worker.

Key decisions

  • No framework, no bundler — plain ES modules loaded by index.html. Easiest to reason about and to serve statically.
  • All paths are relative so the app runs unchanged at a domain root or under a GitHub Pages subpath (/repo/).
  • Single source of truth for exercises: js/data/exercises.json — the app and the SVG generator both read it.
  • Units are metric (kg/cm). Calculations are estimates only (see Extending).
